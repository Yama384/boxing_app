# 🥊 Kampfsport Trainings-App

Eine mobile App für Kampfsportler, die dabei hilft, Trainingseinheiten zu planen, zu dokumentieren und die eigene Entwicklung langfristig zu verfolgen.

Die App wurde mit **Flutter und Dart** entwickelt.

## 📱 Funktionen

### 🏠 Dashboard

* Übersicht über wichtige Trainingsinformationen
* Schneller Zugriff auf die wichtigsten Funktionen

### ⏱️ Trainingstimer

* Timer für Trainingseinheiten
* Unterstützung für Intervalltraining
* Anpassbare Trainings- und Pausenzeiten

### 📅 Trainingsplanung

* Erstellung und Verwaltung von Trainingsplänen
* Planung von Trainingseinheiten über die Woche

### 📖 Trainingslogbuch

Dokumentation von absolvierten Trainingseinheiten mit:

* Trainingsart
* Trainingsdauer
* Trainingsintensität
* Technik und Trainingsinhalte
* Persönlicher Reflexion

### 📝 Check-in

Vor dem oder nach dem Training können wichtige Faktoren dokumentiert werden:

* Energielevel
* Fokus
* Schlafqualität
* Schmerzen bzw. Schmerzbereiche

### 💪 Maximalkraft

* Dokumentation der persönlichen Kraftentwicklung
* Übersicht über Fortschritte bei verschiedenen Übungen

### ⚙️ Einstellungen

* Anpassung der Sprache
* Anpassung von App-Einstellungen

## 🚀 Installation

### Voraussetzungen

* Flutter SDK
* Dart SDK
* Android Studio oder Xcode
* Emulator oder physisches Smartphone

### Repository klonen

```bash
git clone https://github.com/Yama384/DEIN-REPOSITORY.git
```

In das Projektverzeichnis wechseln:

```bash
cd DEIN-REPOSITORY
```

Abhängigkeiten installieren:

```bash
flutter pub get
```

App starten:

```bash
flutter run
```
